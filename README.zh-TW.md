# PlayCut

[English](README.md) | **繁體中文**

給 Windows / macOS 用的影片播放 / 標記 / 剪輯工具。**不會跳更新通知**。

做這個的四個理由：

| 你要的 | 這裡怎麼做 |
|---|---|
| 播放速度調整 | 0.25×–4×，下拉選單或 `[` `]`，也可以直接打數字。長按畫面 = 暫時兩倍速 |
| 觸控左右滑拉進度 | 觸控螢幕單指左右滑；上下滑 = 音量；兩指點 = 全螢幕；觸控板兩指也可以 |
| 聲音延遲校正 | 底部有 ±ms 的調整框，`Ctrl+←` `Ctrl+→` 各 10ms（間隔可在設定裡改），**而且可以烘焙進輸出檔** |
| 插旗標 → 匯出片段 | 按 `M` 插旗標，第 1 個是起點、第 2 個是終點，匯出時**起點完全精準，沒有 LosslessCut 的偏移問題** |

## 安裝

1. 沒有 Python 的話先裝一個（3.10 以上）：<https://www.python.org/downloads/>
   安裝時**記得勾選 "Add Python to PATH"**。
2. 點兩下 **`setup.bat`**。
   它會建立一個獨立環境、裝好套件，並自動下載 `libmpv-2.dll`（播放核心）
   與 `ffmpeg.exe` / `ffprobe.exe`（剪輯核心）到 `bin\` 資料夾。
3. 點兩下 **`run.bat`** 啟動。

想要一個完全免安裝、可以複製到別台電腦的單一執行檔，
安裝完之後再跑一次 **`build.bat`**，成品在 `dist\PlayCut.exe`。

如果比較在意啟動速度，改跑 **`build_folder.bat`**：成品是 `dist\PlayCut\` 整個資料夾
（另附一份 `dist\PlayCut.zip`），把整個資料夾複製到別台電腦、執行裡面的 `PlayCut.exe` 即可。
不用每次解壓，開啟比較快，也比較不會被防毒誤判。

出問題時改用 **`debug.bat`** 啟動，它會保留命令列視窗並印出詳細訊息。

> `setup.bat` 下載失敗的話，畫面上會列出手動下載的網址與放置位置，照著做就行。

### Windows on ARM（Snapdragon 等 ARM 筆電）

步驟和上面一樣，只要**裝 ARM64 版的 Python**
（python.org 下載頁的「Windows installer (ARM64)」）。
`setup.bat` 會依照 Python 的架構自動下載 ARM64 版的 libmpv 與 ffmpeg，
`build_folder.bat` 的成品則叫做 `dist\PlayCut-arm64.zip`。

- 用 x64 版 Python 也可以，只是整個程式會透過 Windows 的模擬執行，比較慢。
- 從 x64 電腦整個複製過來的專案資料夾也能用：`bin\` 裡架構不對的檔案會在
  `setup.bat` / `build*.bat` 時自動換成正確的版本。
- ARM64 版 libmpv 的壓縮檔需要 7-Zip 才能解開；沒裝 7-Zip 時會自動下載官方的 `7zr.exe`。
- 畫面是透過 OpenGL 繪製的。ARM 電腦如果出現黑畫面，到 Microsoft Store 安裝
  「OpenCL and OpenGL Compatibility Pack」通常就能解決。

### 用 GitHub Actions 自動打包（x64 + ARM64）

專案裡附了 `.github/workflows/build-windows.yml`，不需要 ARM 電腦也能做出 ARM64 版：
到 GitHub 專案頁面 → **Actions** → **Build Windows** → **Run workflow**，
跑完之後在該次執行頁面最下面的 Artifacts 下載
`PlayCut-win-x64.zip` 與 `PlayCut-win-arm64.zip`。
推送 `v` 開頭的 tag（例如 `v1.2.0`）時，兩個 zip 也會自動附加到同名的 Release。

### macOS

1. 先裝 [Homebrew](https://brew.sh)（已經有就跳過）。
2. 在 Finder 點兩下 **`setup_mac.command`**。
   它會用 Homebrew 裝好 `mpv`（播放核心）與 `ffmpeg`（剪輯核心），
   並建立一個獨立的 `.venv-mac` 環境（跟 Windows 的 `.venv` 分開，同一個資料夾兩邊共用也不會打架）。
3. 點兩下 **`run_mac.command`** 啟動。出問題時在終端機跑 `./run_mac.command --debug` 看詳細訊息。

想要一個可以拖進「應用程式」資料夾的 App，再跑一次 **`build_mac.command`**，
成品是 `dist/PlayCut.app`，另附 `dist/PlayCut-mac.zip` 方便傳給別台 Mac。

注意事項：

- **只能在 Mac 上打包**，而且成品只能在同一種晶片（Apple Silicon 或 Intel）的 Mac 上執行。
- App 沒有經過 Apple 公證，別台 Mac 第一次開啟會被擋：在 App 上按右鍵 → **打開**；
  macOS 15 以後改成到「系統設定 → 隱私權與安全性」按「仍要打開」。
- 如果點兩下 `.command` 沒反應或顯示「沒有權限」，在終端機進入專案資料夾執行一次
  `chmod +x *.command`。
- Mac 沒有觸控螢幕，所以單指滑動的手勢用不到；觸控板兩指左右滑 = 拉進度、上下滑 = 音量。
- 快捷鍵裡的 `Ctrl` 在 Mac 上都是 `⌘ Cmd`（例如 `⌘O` 開啟、`⌘E` 匯出、`⌘←` `⌘→` 調聲音延遲）。
- 已裝好的 App 支援 Finder 的「打開方式 → PlayCut」與拖到 Dock 圖示開啟。
- 錯誤記錄會寫在 `~/Library/Logs/PlayCut/playcut_error.log`。

## 基本用法

把影片**拖進視窗**，或 `Ctrl+O` 開啟。

### 插旗標、剪片段

1. 播到想要的位置（用 `,` `.` 可以一格一格移動，找到剛好的那一格）
2. 按 `M` 插一個旗標
3. 播到結束的位置，再按一次 `M`
4. `Ctrl+E` → 選模式 → 開始匯出

旗標會自動交替：第 1 個是**起點**、第 2 個是**終點**、第 3 個又是起點……
所以「01:00 插一個、02:00 插一個」就會得到 01:00–02:00 這一段。
也可以在右邊面板把某個旗標**固定**成起點或終點。

旗標會自動存成影片旁邊的 `影片檔名.mp4.playcut.json`，下次開同一個影片會自動讀回來。

### 三種匯出模式

| 模式 | 起點精準度 | 速度 | 畫質 |
|---|---|---|---|
| **智慧剪輯**（預設） | **完全精準** | 接近無損剪輯 | 只有開頭一小段重新編碼，其餘原封不動 |
| 全部重新編碼 | 完全精準 | 最慢 | 依 CRF 設定（預設 22，一般人看不出差別；16 接近無損但檔案約大一倍） |
| 純無損複製 | **會往前偏移**（可能好幾秒） | 最快 | 完全無損 |

**智慧剪輯**是解決你說的 LosslessCut 問題的關鍵：
無損剪輯只能從「關鍵影格」開始切，你選 01:00 但前一個關鍵影格在 00:58，
輸出就會多出 2 秒（或開頭畫面破掉）。
智慧剪輯只把 **01:00 到下一個關鍵影格**那一小段重新編碼，
後面全部直接複製串流 —— 起點完全精準，速度幾乎跟無損一樣。

### 讓檔案變小

智慧剪輯和純無損複製都是直接複製原始畫面，檔案大小 ≈ 原片位元率 × 長度，不會變小。
要縮小檔案，在匯出視窗的「壓縮（讓檔案變小）」設定（任何一項有作用時會自動改成整段重新編碼）：

- **影片編碼**：H.265 / HEVC 同樣畫質下約小 30～50%（較慢，輸出 .mp4 會自動標成 `hvc1`，Apple 裝置也能播）
- **解析度上限**：1080p / 720p / 480p…，以短邊計算，直式影片也適用，只縮不放大
- **聲音位元率**：自動時雙聲道最多 160 kbps
- **目標大小**：輸入 MB，依長度自動算位元率，用 CPU 兩階段編碼，輸出會略小於設定值
  （不合併時是每個檔案的大小，合併時是整個檔案）

實測 10 秒 1080p 片段：智慧剪輯 16.3 MB → 重新編碼 CRF 22 8.4 MB → H.265 + 720p 3.4 MB；指定 2 MB 輸出 1.9 MB。

實測（25fps、每 5 秒一個關鍵影格、從 12.36 秒切）：

```
智慧剪輯    首格 vs 指定位置  PSNR 46.3 dB  ✅ 完全對上，耗時 0.8 秒
全部重編碼  首格 vs 指定位置  PSNR 46.3 dB  ✅ 完全對上，耗時 1.2 秒
純無損      首格 vs 指定位置  PSNR 14.9 dB  ❌ 跳到 10.0 秒的關鍵影格
影音同步：智慧剪輯 0–1 ms、接合點無跳動
```

### 聲音延遲

影片聲音對不上時，調底部的「延遲」框（正值＝聲音延後播放，單位 ms）。
`Ctrl+←` / `Ctrl+→` 或延遲欄旁的 − / + 每次 ±10ms，按「0」歸零。每次調整的量可以在「設定 → 聲音」改。

匯出時對話框會問要不要**把這個延遲套用到輸出檔**。勾起來的話，
輸出檔的聲音就跟你在播放器裡聽到的一模一樣（畫面取 `[起,終]`、聲音取 `[起-延遲, 終-延遲]`）。
套用延遲時聲音會重新編碼，畫面仍然維持原樣。

### 字幕

支援 `.srt` / `.ass` / `.ssa` / `.vtt` / `.sub` / `.idx` / `.sup` / `.smi` 外掛字幕，以及影片內嵌的字幕軌。

- **自動載入**：跟影片同名（或檔名開頭相同）的字幕會自動掛上，例如 `abc.mp4` → `abc.srt`、`abc.zh-TW.srt`。
  有多條字幕時優先選繁體中文。
- **手動載入**：把字幕檔拖進視窗（可以跟影片一起拖），或「字幕 → 載入字幕檔…」（`Ctrl+L`）。
- **切換 / 關閉**：底部的「字幕」按鈕或「字幕」選單可以選字幕軌；`J` 依序切換、`V` 顯示 / 隱藏。
- **字幕延遲**：`Z` / `X` 每次 ∓100ms（正值＝字幕晚出現），`Shift+Z` 歸零。
- **大小 / 位置**：`Alt+↑` `Alt+↓` 放大縮小、`Alt+Shift+↑` `Alt+Shift+↓` 上下移動（設定會記住）。
- **編碼**：UTF-8、UTF-16、Big5、GBK 的字幕都能正確顯示。

匯出時，對話框的「字幕」區塊會用**播放器目前顯示中的字幕**（連同字幕延遲）：

- **另存對應的 .srt**：每個輸出檔旁邊產生同名 `.srt`，時間已經對齊片段（合併時會接續排好）。不影響剪輯速度。
- **燒錄字幕到畫面**（硬字幕）：字幕直接畫進影像，這個選項會強制整段重新編碼。

圖像型字幕（PGS `.sup`、VobSub `.idx/.sub`）可以播放，但不能另存 .srt 或燒錄。

### 截圖

擷取目前這一格畫面，存成**影片原始解析度**的圖檔（跟視窗大小無關，也不會拍到進度條或畫面提示）。

- **含字幕**（`S`，或底部的 📷 按鈕）：影片 + 目前顯示中的字幕，跟畫面上看到的一樣。字幕隱藏時就跟影片畫面相同。
- **只有影片畫面**（`Shift+S`，或 📷 右邊的箭頭）：不含字幕。
- 檔名：`影片名_時-分-秒.毫秒.png`，含字幕的版本後面加 `_sub`；同名不會覆蓋，會自動加 `(2)`、`(3)`…
- 預設存在影片旁邊；「截圖」選單可以改成自訂資料夾、改用 JPG、截圖後同時複製到剪貼簿。
- 影片所在的資料夾寫不進去時（例如唯讀光碟），會改存到「圖片\PlayCut」。

### 速度與短影音裁切

匯出對話框的「速度與短影音裁切」區塊：

- **套用播放速度**：預設帶入播放器目前的速度，可直接改數字（0.1×–10×）。畫面用 `setpts`、聲音用 `atempo` 變速（音高不變），另存的 .srt 時間也會跟著縮放。
- **裁切比例**：1:1（1080×1080）、4:5（1080×1350）、9:16（1080×1920）、16:9（1920×1080）。從畫面中取該比例最大的區域，可選置中 / 靠左上 / 靠右下，再縮放到標示的解析度（可取消縮放）。等同於：

  ```
  ffmpeg -i 1.mp4 -vf "crop=ih*4/5:ih,scale=1080:1350" 1_short_4x5.mp4
  ```

套用速度或裁切時一律整段重新編碼；輸出檔名會自動加上 `_2x`、`_4x5` 之類的後綴。

### 系統匣常駐（Windows）

關掉視窗時 PlayCut 不會真的結束，而是縮到右下角的系統匣，下次開啟（雙擊 exe、雙擊影片檔、點系統匣圖示）幾乎瞬間出現。

- 縮到系統匣時會停止播放、存好旗標，下次叫出來是乾淨的視窗
- **5 分鐘**內沒再叫出來就會自動完全結束，不佔記憶體
- 已經在背景時再開一次 PlayCut，檔案會交給原本那個開，不會開出第二個視窗
- 要真的結束：系統匣圖示右鍵 →「完全結束」，或 檔案 → 離開（Ctrl+Q）
- 不想要這個功能：檔案 →「關閉視窗時縮到系統匣」取消勾選
- 需要同時開兩個視窗時，可用 `PlayCut.exe --new-instance`

| `[` `]` | 降速 / 加速 |

| `Alt+Shift+↑` `Alt+Shift+↓` | 字幕上移 / 下移 |

在備註欄打字時，單鍵快速鍵會自動讓路，不會誤觸。

### 設定視窗

「檢視 → 設定…」（`Ctrl+,`）把常用選項集中在一起：

| 分頁 | 可以改的東西 |
|---|---|
| 播放 | 倒退 / 快轉的秒數（小 / 中 / 大三段）、加速 / 降速間隔、觸控滑動靈敏度、暫停標示 |
| 聲音 | 聲音延遲每次調整幾 ms、音量每次調整幾 % |
| 字幕 | 字幕延遲每次調整幾 ms |
| 截圖 | 圖檔格式、複製到剪貼簿、存放資料夾 |
| 畫面 | HDR 色調映射、動態峰值偵測、色彩增強 |
| 一般 | 介面語言、關閉時縮到系統匣（Windows） |
| 快捷鍵 | 同下方「自訂快捷鍵」 |

改了秒數 / 間隔，選單與快捷鍵的名稱會跟著變（例如「倒退 3 秒」）。每一頁都有「恢復本頁預設」。

### 自訂快捷鍵

「檢視 → 自訂快捷鍵…」（或設定視窗的「快捷鍵」頁）可以改每一個功能的按鍵：點「快捷鍵」欄位、直接按下想要的組合即可，
按 ⓧ 清空 = 不指定。按鍵重複時會標紅色、不能套用。
另外多了幾個預設沒綁鍵、可以自己指定的功能：倒退 / 快轉 10 秒、音量 ±5、靜音。
設定會記住，下次開啟照樣生效；按鈕提示與 `F1` 說明也會顯示你改過的按鍵。

### 介面語言

支援 **繁體中文、简体中文、English、日本語**。第一次開啟時跟隨系統語言
（系統是繁中 / 港澳 → 繁中、簡中 → 简体中文、日文 → 日本語，其他一律英文）。

要手動切換：「檢視 → 語言 / Language」，選好後會問要不要立即重新啟動（重新啟動後生效，
目前開著的影片會自動重新開啟、旗標會先存好）。選「跟隨系統」可以改回自動判斷。
選單標題一律附上英文「Language」，就算不小心切到看不懂的語言也找得回來。

新增或修改介面文字時：程式裡直接寫繁中原文並包上 `tr("…")`，
再到 `playcut/locales/` 的 `en.py`、`zh_CN.py`、`ja.py` 補上翻譯。
跑 `python tools/i18n_keys.py` 可以列出還沒翻譯的字串。

| 動作 | 功能 |
|---|---|
| 左右滑 | 拉進度（滑動中即時預覽，放開才真的跳過去） |
| 上下滑 | 音量 |
| 觸控單指點（點哪裡都一樣）/ 滑鼠單擊 | 播放 / 暫停 |
| 觸控兩指點 | 切換全螢幕 |
| 滑鼠雙擊左 1/3 · 右 1/3 · 中間 | −10 秒 · +10 秒 · 全螢幕 |
| 滑鼠中鍵 | 切換全螢幕 |
| 長按 | 暫時兩倍速，放開恢復 |
| 觸控板兩指左右 / 上下 | 拉進度 / 音量 |

滑動靈敏度可在「檢視 → 觸控滑動靈敏度」調整（預設：整個螢幕寬 = 120 秒）。

## 檔案結構

```
PlayCut\
```

## 疑難排解

**點 run.bat 沒反應 / 一閃就沒了** — 改用 `debug.bat` 啟動，錯誤訊息會留在視窗裡。
另外程式若啟動失敗也會在 PlayCut 資料夾寫下 `playcut_error.log`。

**啟動就說找不到 libmpv** — `bin\libmpv-2.dll` 沒下載成功，重跑 `setup.bat`，
或照它印出的網址手動下載放進 `bin\`。

**畫面全黑、只有聲音** — 顯示卡驅動與硬體解碼的問題。
在 `run.bat` 裡的 `start` 那行前面加一行 `set PLAYCUT_HWDEC=no` 再試。

**匯出按鈕說找不到 ffmpeg** — `bin\ffmpeg.exe` 沒下載成功，同上。

**.bat 檔為什麼是英文的** — cmd.exe 是用「位元組位置」在讀批次檔，
批次檔裡如果中途 `chcp` 切換編碼頁、內容又是 UTF-8 中文，cmd 會讀錯位置直接中斷
（視窗一閃就關）。所以這幾個 .bat 刻意寫成純 ASCII，中文訊息全部交給 Python 印。

**想傳額外的 mpv 參數** — 設環境變數 `PLAYCUT_MPV_OPTS`，
例如 `set PLAYCUT_MPV_OPTS=scale=bilinear,video_sync=display-resample`。
